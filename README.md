# Scrabble App

## Introduction

<a href="https://en.wikipedia.org/wiki/Scrabble">Scrabble</a> is a word game in which two to four players score points by placing tiles, each bearing a single letter, onto a game board divided into a 15×15 grid of squares. The tiles must form words that, in crossword fashion, read left to right in rows or downward in columns and are included in a standard dictionary.

### Apps

- scrabble-app

## Play Scrabble

You can play a game of Scrabble here.

- <a href="https://scrabble-app.vercel.app/">https://scrabble-app.vercel.app/</a>

## Getting Started

After you clone the Git repository, you can run the following <a href="https://pnpm.io/">pnpm</a>
commands.

When this repository is connected to Vercel, pushes to `main` are deployed automatically.

- `pnpm install` - install packages
- `pnpm build` - build production app
- `pnpm dev` - run development app
- `pnpm test` - run tests interactively
- `pnpm test:all` - run all tests once
- `pnpm typecheck` - type-check the repository
- `pnpm lint:check` - check lint rules
- `pnpm lint:fix` - apply lint fixes
- `pnpm format:check` - check formatting without changing files
- `pnpm format:fix` - format code
- `pnpm check` - run type-checking, linting, formatting, and all tests
